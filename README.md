# Human-and-Animal-identification-in-Flood-and-Non-Flooded-Areas-using-Yolo
Overview
This project uses a pre-trained YOLO (You Only Look Once) object detection model to identify humans and animals in both flooded and non-flooded regions using aerial or ground-level images. The goal is to support disaster response teams by automating the detection process, improving the speed and accuracy of rescue planning.

🚀 Features
✅ Detects humans and animals in images.

✅ Classifies scenes as flooded or non-flooded.

✅ Uses transfer learning with YOLOv5 for accurate and fast predictions.

✅ Can process batch images and output annotated results.

🛠️ Technologies Used
Programming Language: Python

Framework: PyTorch

Model: YOLOv5 (Pre-trained, fine-tuned)

Libraries: OpenCV, NumPy, Matplotlib

Tools: Jupyter Notebook, Google Colab, Roboflow (for dataset management)
